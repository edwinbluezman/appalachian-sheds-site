# Appalachian Sheds website

This is the active build of appalachiansheds.com: 12 custom building models (Appalachian
Farmhouse, Laurel Ridge, Urban Studio, Grand Depot, Carriage Lane, Nordic Retreat, Foxfire
Cottage, Pine Ridge Shed, Appalachian Barn, Appalachian Firewood Shed, Country Cottage with
Shed Dormer, Antique Saltbox), plus galleries, options/upgrades pages, and planning guides.

Recovered from a ChatGPT/Cloudflare build that was lost when its conversation hit a length
limit — see `recovered-chatgpt-build-2026-11-24/` for the recovered static-HTML snapshot this
is being rebuilt from as a proper Astro project.

An earlier, different build of this site (5 different models, a separate set of planning
guides) previously lived in this repo as reference material. It has been removed to avoid
confusion with the active build above; it remains available in this repo's git history if
ever needed.
